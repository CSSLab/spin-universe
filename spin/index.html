SPIN: Text classification from internal neurons

Difan Jiao*, Yilun Liu*, Zhenwei Tang, Daniel Matter, Jürgen Pfeffer, Ashton Anderson

June 5, 2024
Findings of ACL 2024 Paper Code Interactive demo
tl;dr

SPIN classifies text using a small set of internal neurons drawn from multiple layers of a frozen language model. We select task-relevant neurons with linear probes, then train a classifier on their combined representations. Across eight pretrained backbones and three classification benchmarks, SPIN improves on classifiers using the final layer alone. It can also stop before the final layer and work on top of models that have already been fine-tuned.

Introduction

A common way to classify text with a language model is to train a classification head on its final hidden states. For a movie review, for example, the head learns to predict whether the sentiment is positive or negative. The model's intermediate layers also contain information about the text, but a classifier built only on the final layer leaves those representations unused.

We introduce SPIN, a model-agnostic framework that sparsifies and integrates internal neurons from intermediate layers for text classification. SPIN uses linear probing to select salient neurons layer by layer. The selected neurons are then combined into features for a classification head, while the language model's weights remain untouched.

Sparsifying and integrating internal neurons

The internal representations from all layers of a language model can be obtained in a single forward pass. SPIN uses either hidden states or the intermediate activations of each layer's feed-forward network. We pool these representations over tokens to obtain features of a fixed size for sentences of different lengths.

Selecting neurons within each layer

Not every neuron contributes equally to a particular classification task. Unrelated neurons may introduce noise or unnecessary information, so we first train a linear probe on each layer's frozen representations using the task's labels.

We use L1-regularized logistic regression, which encourages sparse weights. The magnitudes of the learned weights indicate which neurons contribute most to the probe's prediction. Within each layer, we normalize these magnitudes, sort them, and retain the smallest set whose cumulative weight reaches a chosen threshold.

Combining signals across layers

The integration step simply concatenates the selected neuron representations. We train a linear classification head on these combined features. This preserves each neuron's representation while allowing the classifier to use information from several depths of the model.

Both components matter in our ablations on GPT2-XL and IMDb. Selecting neurons with the probes outperforms random selection, and combining neurons across layers outperforms using the best individual layer at each tested exit depth.

What we find

Classification across model families

We evaluate SPIN on encoder models, decoder models, and encoder-decoder models, using IMDb and SST-2 for sentiment classification and EDOS for detecting online sexism. The baseline trains a classification head on the frozen final-layer representations. Both approaches learn from the datasets' labels.

Each version of SPIN outperforms its corresponding baseline across all three benchmarks. For Flan-T5-S on EDOS, macro-F1 rises from 59.62 to 74.51, a relative improvement of about 25%. SPIN also improves models whose baseline performance is already higher: GPT2-XL's IMDb accuracy increases from 91.86% to 94.92%.

SPIN can also be applied after fine-tuning. On the publicly available fine-tuned checkpoints we tested, it improves on the corresponding final-layer classifiers in every available model-dataset comparison.

Training and inference costs

SPIN does not backpropagate through the language model. Feature extraction requires forward passes with frozen weights, and trainable parameters are limited to the probes and classification head. At inference time, SPIN can make a prediction before the entire forward pass finishes. We select and combine neurons from only the layers up to an exit point. On IMDb, GPT2-XL reaches 94.73% accuracy using 60% of its layers, compared with 94.92% using all layers. Flan-T5-XL reaches 96.12% in both settings. The useful exit depth depends on the backbone; the full early-exit results report this tradeoff for all eight models.

What the selected neurons reveal

The linear probes give us a way to inspect which neurons contribute to a task. Because integration concatenates the selected representations, we can examine their individual signals as well as the predictions of the combined classifier.

In the GPT2-XL sentiment example below, individual salient neurons carry signals that distinguish positive and negative reviews. Combining the selected neurons from successive layers improves the classifier's separation of the two classes.

A classifier trained on pooled sentence representations can also be applied to individual tokens by bypassing pooling. This gives a token-wise breakdown of the prediction, which can be explored in our interactive demo. In decoder models, each token's representation includes the preceding context, so these scores reflect the text read so far.

Discussion

SPIN shows that intermediate representations can be useful features for text classification with a frozen language model. Selecting neurons within each layer and integrating them across layers improves the tested classifiers, and early exits offer a way to reduce inference work.

The approach requires access to the model's internal representations, so it cannot be used with a text-only API. We also use a simple linear classification head; more expressive heads remain a possible extension. Our full paper includes the mathematical formulation, hyperparameter choices, additional experiments and limitations.
